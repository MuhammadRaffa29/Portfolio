# Muhammad Raffa — Personal Portfolio

A responsive personal portfolio built with React, Vite, Tailwind CSS, and Lucide icons.

## Run locally

1. Install Node.js (LTS).
2. Extract this project.
3. Open a terminal in the project folder.
4. Run:

```bash
npm install
npm run dev
```

5. Open the local URL shown by Vite (usually `http://localhost:5173`).

## Build for deployment

```bash
npm run build
```

The production files will be generated in the `dist` folder.

## Personalize

- Replace `public/profile.png` with another portrait if desired.
- Update the profile details and project descriptions in `src/App.jsx`.
- Update the email, Instagram, and GitHub links in `src/App.jsx`.

## Deploy to Vercel

Import the project into Vercel or connect its GitHub repository. Vercel should detect Vite automatically. Use `npm run build` as the build command and `dist` as the output directory.
